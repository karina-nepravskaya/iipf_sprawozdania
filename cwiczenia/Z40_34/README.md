# Szablon ćwiczenia

Skopiuj ten katalog, zanim rozpoczniesz nowe ćwiczenie:

`cp -R cwiczenia/00_szablon_cwiczenia cwiczenia/01_nazwa_cwiczenia`

Następnie uzupełnij najpierw:

1. `brief/RZECZYWISTY_PRZEBIEG.md`;
2. `brief/WYMAGANIA_PROWADZACEGO.md`;
3. oryginalną instrukcję w `instructions/`;
4. dane, zdjęcia i notatki z pomiarów w `data/raw/`.

Dopiero potem uruchom etap analizy opisany w głównym `AGENTS.md`.
